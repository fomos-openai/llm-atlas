# 03 数据、表示与架构

模型能学到什么，首先由数据决定。数据工程包括来源与许可、采集解析、清洗去重、质量分类、混合配比、污染检测、隐私处理与血缘。公开可访问不等于可以任意训练；高质量也不是一个分类器分数，而是事实、信息密度、多样性、领域覆盖与风险的组合。

Tokenizer 把输入切成 token。不同语言、代码和数字的分词效率不同，直接影响上下文容量和成本。嵌入把 token 映射到连续空间，位置机制则把顺序注入注意力。

## 架构不是孤立指标

Decoder-only Transformer 以统一生成接口成为主流；MoE 让每个 token 只激活少量专家；GQA/MQA 减小 KV cache；状态空间与混合模型探索更低长序列成本；多模态连接器把视觉、语音和视频接入模型。

判断新架构不能只看参数或理论复杂度。训练稳定性、通信、内核、批量、延迟、生态和真实任务共同决定它是否更好。“支持超长上下文”也只说明容量，不证明模型能稳定利用每个位置。
