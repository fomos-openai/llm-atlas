# 08 生产、基础设施与生态

上线不是终点，而是模型第一次接触真实分布。生产系统需要影子流量、灰度、版本固定、观测、反馈、路由、降级和回滚。模型、提示、工具、索引与策略应作为一个版本单元管理。

大模型基础设施受加速器、HBM、互连、网络、存储、电力与供应链约束。理论 FLOPS 不等于真实性能，数据移动、通信和内核成熟度常决定速度。训练是前期投入，推理成本随使用增长，长期高流量产品可能更重视小模型、量化、缓存和路由。

## 生态选择

闭源 API 提供托管和前沿能力；开放权重提供部署控制与本地适配。选择应比较质量、总成本、延迟、数据驻留、许可、锁定、更新稳定和团队运维能力。

领域应用的风险随“建议”到“执行”的权限上升。真正价值来自任务重构与责任设计，而不是把聊天界面覆盖到所有流程。
