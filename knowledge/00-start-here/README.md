# 00 · 从这里开始

大模型技术不是一条“模型越大越强”的单线故事。它是数据、表示、优化、硬件、反馈、推理系统、外部知识、工具、评测和治理共同组成的反馈系统。

## 一张总图

主生命周期可以压缩为：

> 问题定义 → 数据与治理 → 表示与架构 → 预训练 → 后训练 → 评测与安全门 → 推理与服务 → 上下文/知识/工具增强 → 产品运行 → 监控与反馈 → 更新或退役

历史解释这些能力为何出现；现状快照记录能力与可靠性的锯齿边界；未来章节讨论什么可能改变这条链路。

## 四个核心判断

- **模型能力不等于系统能力**：检索、工具、记忆、调度与验证可以显著改变系统表现，也引入新的攻击面。
- **基准分数不等于现实可靠性**：数据污染、任务分布、评审器偏差、成本和时延都会改变结论。
- **后训练决定可用行为，预训练决定广泛先验**：二者互补，不能用提示工程弥补全部训练缺口。
- **未来不是单一路径**：规模化、推理时计算、合成数据、持续学习、Agent、世界模型和治理约束会共同塑造下一阶段。
