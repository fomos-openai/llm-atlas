# 学习路线

## 研究路线

基础 → 架构 → 预训练 → 后训练 → 推理时计算 → 评测 → 前沿问题。重点掌握假设、目标函数、消融实验、数据污染和可复现性。

## 模型工程路线

数据 → 分布式训练 → 稳定性 → 检查点 → 后训练 → 推理效率 → EvalOps。重点掌握吞吐、显存、数值精度、失败恢复与成本。

## 应用工程路线

提示与上下文 → RAG → 工具调用 → Agent → 安全 → 生产生命周期。重点掌握任务分解、证据引用、权限边界、观测与降级。

## 产品与管理路线

生命周期总览 → 评测 → 生产指标 → 经济性 → 应用生态 → 当前快照。重点关注价值、可靠性、采用摩擦和“人仍需负责什么”。

## 安全与治理路线

数据治理 → 安全评测 → 攻击面 → 隐私 → 监控与事件 → 标准与监管 → 未来控制问题。

## 快速路线（约 3 小时）

阅读本章、Transformer、后训练、评测、推理、RAG、Agent、安全、当前快照和未来前沿十个 README；再从地图跳转到需要深入的节点。
