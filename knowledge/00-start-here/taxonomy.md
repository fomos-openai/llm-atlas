# 知识分类法

LLM Atlas 使用四个互补坐标，而不是只按名词分类。

## 生命周期坐标

数据 → 表示 → 架构 → 训练 → 后训练 → 评测 → 推理 → 增强 → 部署 → 反馈。

## 系统层级坐标

- **权重层**：参数、训练目标、内部表示。
- **运行时层**：解码、缓存、并行、路由和服务。
- **上下文层**：提示、检索、记忆、工具和环境状态。
- **应用层**：工作流、用户体验、权限和业务指标。
- **社会技术层**：治理、劳动力、市场、能源和制度。

## 时间坐标

- 稳定基础：数学、经典架构、通用工程规律。
- 活跃前沿：仍在快速变化但已有重复证据的方法。
- 当前快照：明确日期的模型、基准与产业状态。
- 未来情景：包含假设和不确定性的方向判断。

## 证据坐标

- **E1 原始可复现证据**：论文、代码、数据、标准或明确实验。
- **E2 多方一致证据**：多个独立研究或部署观察支持。
- **E3 单方报告**：系统卡、技术报告或厂商数据，需保留上下文。
- **E4 推演**：由趋势推导，尚无充分验证。

一个主题可以同时位于多个坐标。例如 RAG 属于上下文层、部署中增强阶段，既有稳定机制，也有持续变化的多模态与 Agent 化前沿。
