# 01 · 历史源流

大模型来自多条技术线的汇合：符号主义提供可组合表示与推理愿景，统计学习把语言问题转为概率估计，神经网络学习分布式表示，注意力与 Transformer 解除顺序计算瓶颈，规模化训练和人类反馈把通用预测器变成可交互系统。

## 路线

[符号到统计](./symbolic-to-statistical-ai.md) → [神经网络](./neural-networks.md) → [表示学习](./representation-learning.md) → [Seq2Seq 与注意力](./seq2seq-and-attention.md) → [Transformer](./transformer.md) → [规模定律](./scaling-laws.md) → [时间线](./timeline.md)

## 关键转折

- 语言从手写规则转为从语料估计概率；
- 特征从人工设计转为端到端学习；
- 词的离散身份转为连续向量和上下文表示；
- 循环网络转为并行注意力；
- 单任务模型转为预训练基础模型；
- 仅续写文本转为指令、偏好与工具驱动的系统。

原始资料：[Attention Is All You Need](https://arxiv.org/abs/1706.03762)、[Language Models are Few-Shot Learners](https://arxiv.org/abs/2005.14165)、[Scaling Laws for Neural Language Models](https://arxiv.org/abs/2001.08361)。
