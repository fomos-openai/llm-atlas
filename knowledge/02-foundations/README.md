# 02 · 数学与机器学习基础

本章给出理解大模型机制所需的最小基础：向量与矩阵表示、概率分布与估计、信息压缩、梯度优化、深度网络和强化学习。

## 导航

- [线性代数](./linear-algebra.md)：嵌入、投影、矩阵乘法、低秩结构。
- [概率与统计](./probability-and-statistics.md)：似然、采样、不确定性与估计偏差。
- [信息论](./information-theory.md)：熵、交叉熵、KL 散度。
- [优化](./optimization.md)：梯度、Adam、学习率和稳定性。
- [深度学习](./deep-learning.md)：表示、归纳偏置、正则化与泛化。
- [强化学习](./reinforcement-learning.md)：策略、回报、信用分配和奖励投机。

学习这些概念的目标不是完成数学百科，而是能回答：优化目标究竟奖励什么，训练信号从哪里来，估计有什么偏差，系统为何失效。
