# 03 · 数据

数据决定模型学习到的世界分布，也是版权、隐私、偏见、安全和评测污染的主要入口。高质量数据工程不是“抓更多网页”，而是建立来源、许可、质量、去重、混合和删除能力。

## 生命周期

[来源与许可](./sources-and-licensing.md) → [采集解析](./collection-and-parsing.md) → [清洗去重](./cleaning-and-deduplication.md) → [质量与配比](./quality-and-mixtures.md) → [污染检测](./contamination.md) → [合成数据](./synthetic-data.md) → [多语言](./multilingual-data.md) → [治理与溯源](./governance-and-provenance.md)

## 最小数据卡

每个数据集至少记录来源、时间范围、许可依据、语言/模态、采样方法、清洗规则、去重粒度、敏感信息处理、已知偏差、版本哈希和可删除路径。
