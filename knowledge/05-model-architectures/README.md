# 05 · 模型架构

架构定义信息如何流动、哪些参数参与一次计算，以及训练和推理成本如何随规模变化。当前主流仍以 Transformer 为核心，但稀疏专家、长上下文、状态空间和多模态连接不断重塑边界。
