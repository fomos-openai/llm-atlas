# 07 · 后训练

后训练把基础预测器塑造成可交互、可推理、可约束的模型。训练信号来自示范、成对偏好、奖励模型、规则/验证器和环境反馈。

## 方法族

[SFT](./supervised-fine-tuning.md) · [偏好学习](./preference-learning.md) · [RLHF/RLAIF](./rlhf-and-rlaif.md) · [DPO](./direct-preference-optimization.md) · [奖励模型与验证器](./reward-models-and-verifiers.md) · [推理强化学习](./reasoning-reinforcement-learning.md) · [蒸馏](./distillation.md) · [领域与持续适配](./domain-and-continual-adaptation.md)

后训练的真正目标不是让模型“更会说”，而是在能力、诚实、帮助性、安全、风格、成本和拒答之间形成可测的行为边界。
