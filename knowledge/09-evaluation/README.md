# 09 · 评测

评测回答的不只是“模型多强”，而是“在什么条件、成本和风险下，对哪些用户与任务足够可靠”。单一平均分无法代表真实系统。

## 评测栈

[通用能力](./capability-evaluation.md) · [推理与代码](./reasoning-and-code.md) · [多模态](./multimodal-evaluation.md) · [Agent](./agent-evaluation.md) · [安全](./safety-evaluation.md) · [人工与模型评审](./human-and-model-judges.md) · [污染与榜单博弈](./contamination-and-gaming.md) · [EvalOps](./evalops.md)

2026 年的重要现实是许多基准快速饱和，而复杂现实任务仍存在明显失败，因此评测必须不断更新并重视任务有效性。
