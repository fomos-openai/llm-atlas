# 11 · 上下文与知识增强

上下文工程把模型、指令、证据、记忆和工具状态组合成一次可控计算。它比单条“神奇提示词”更接近生产系统的真实工作。

[提示](./prompting.md) · [上下文工程](./context-engineering.md) · [RAG](./retrieval-augmented-generation.md) · [检索与重排](./retrieval-and-reranking.md) · [事实锚定与引用](./grounding-and-citations.md) · [记忆](./memory.md) · [上下文协议](./context-protocols.md)

外部知识提高可更新性和可追溯性，但系统上限由召回、上下文组织、模型使用证据的能力和来源信任共同决定。
