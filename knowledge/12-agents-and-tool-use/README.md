# 12 · Agent 与工具使用

Agent 是围绕模型构建的闭环系统：观察状态、选择动作、调用工具、读取结果、更新计划，直到完成、失败或请求人工介入。真正的自主性来自可执行权限，不来自措辞。

[Agent 架构](./agent-architecture.md) · [工具调用](./function-and-tool-calling.md) · [计算机/浏览器使用](./computer-and-browser-use.md) · [编码 Agent](./coding-agents.md) · [多 Agent](./multi-agent-systems.md) · [互操作协议](./interoperability-protocols.md) · [长时任务](./long-running-agents.md) · [具身 Agent](./embodied-agents.md)

可靠 Agent 的核心不是无限循环，而是明确状态、有限权限、可观测进度、预算、停止条件和可恢复检查点。
