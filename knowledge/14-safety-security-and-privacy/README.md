# 14 · 安全、Security 与隐私

安全不是单一“拒答率”，而是模型、上下文、工具、权限、数据和运营共同构成的防御体系。能力越接近现实行动，系统级风险越重要。

防御原则：最小权限、分层隔离、默认可逆、来源不可信、关键动作需确认、持续评测与可观测事件响应。
