# 2026-09 模型版图

最后核验：2026-09-30。此页不是实时排行榜。

## 竞争轴已经多维化

前沿模型不再只比较静态知识题，而是同时竞争复杂推理、代码与软件工程、多模态实时交互、工具/计算机使用、长任务、上下文长度、延迟、价格和安全边界。

## 闭源与开放权重

闭源前沿系统继续依赖高资本训练与专有后训练/服务栈；开放权重生态在部署控制、蒸馏、领域适配和成本优化上活跃。两者差距随任务而变，不能用单一平均分概括。

## 从模型到系统

越来越多可见能力来自推理时计算、检索、代码执行、浏览器/计算机使用和 Agent 编排。因此应报告“模型 + 工具 + 预算 + 环境”，而不是只报告模型名。

## 可靠性仍呈锯齿状

模型可以在高难数学、科学和代码任务上达到很高水平，却仍会在简单感知、事实、权限和长时一致性上失败。Stanford AI Index 2026 将这种不均衡描述为持续存在的 jagged intelligence，并指出 Agent 在结构化计算机任务上明显进步但仍有大量失败。

来源：[AI Index 技术表现](https://hai.stanford.edu/ai-index/2026-ai-index-report/technical-performance)。
