# 18 · 当下处于什么阶段

本章保存带日期的领域快照，不覆盖旧版本。当前快照为 [2026-09](./2026-09/model-landscape.md)。

## 读法

- 模型发布与榜单会快速变化，结论必须看日期；
- 用能力边界、成本和可靠性描述阶段，而不是宣布单一“最强模型”；
- 区分实验演示、受控部署和大规模稳定运营；
- 对厂商自报结果保留 E3 证据等级，等待独立复现。

截至 2026 年，前沿能力继续提升，模型竞争从单纯质量扩展到推理、Agent、多模态、成本、可靠性和安全；同时基准饱和、评测失真和现实任务失败仍是核心约束。

主要参考：[Stanford AI Index 2026](https://hai.stanford.edu/ai-index/2026-ai-index-report)、[OpenAI Deployment Safety Hub](https://deploymentsafety.openai.com/)。
