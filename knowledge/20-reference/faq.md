# 常见问题

## 大模型等于 Transformer 吗？

不等于。Transformer 是主流架构，大模型还包含数据、训练、后训练、推理系统和产品控制；也存在状态空间与混合架构。

## 参数越多越好吗？

不必然。数据、训练量、架构、后训练和推理预算决定效果；任务成本可能偏好更小模型。

## 长上下文能替代 RAG 吗？

不能普遍替代。长上下文增加容量，RAG 提供选择、更新、权限和引用。二者常组合。

## Agent 是更聪明的模型吗？

Agent 是模型外的行动闭环。它可能使用相同模型，但通过工具、状态和规划扩大能力，也扩大风险。

## 开放权重就是开源吗？

不一定。还要看代码、数据、训练方法和许可证是否开放。

## 基准高分代表可部署吗？

不代表。还需可靠性、安全、成本、延迟、隐私和真实任务评测。
