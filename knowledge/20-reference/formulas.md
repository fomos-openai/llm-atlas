# 常用公式

## 自回归分解

`p(x_1…x_T) = ∏_{t=1}^T p(x_t | x_<t)`

## 交叉熵损失

`L = -Σ_t log p_θ(x_t | x_<t)`

## 缩放点积注意力

`Attention(Q,K,V) = softmax(QKᵀ / √d_k)V`

## KL 散度

`D_KL(P||Q) = Σ_x P(x) log(P(x)/Q(x))`

## 强化学习目标

`J(θ) = E_{τ~π_θ}[Σ_t γ^t r_t]`

## 检索常用指标

`Recall@k = 在前 k 个结果中找到相关项的查询比例`

公式只描述目标或算子；实际系统行为还由数据、优化、采样和实现决定。
