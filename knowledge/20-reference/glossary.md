# 术语表

| 术语 | 简释 |
|---|---|
| Attention | 根据查询与键的相似度加权聚合值 |
| Context window | 单次推理可条件化的 token 范围 |
| Embedding | 对象的连续向量表示 |
| Foundation model | 在广泛数据上训练、可适配多任务的模型 |
| Grounding | 用指定外部证据约束输出 |
| Hallucination | 生成无依据或错误内容 |
| Inference-time compute | 在回答阶段通过采样、搜索、验证等投入的计算 |
| LLMOps | 大模型数据、评测、部署与观测的工程体系 |
| LoRA | 用低秩增量参数进行高效适配 |
| MCP | 模型客户端连接上下文资源与工具的开放协议 |
| MoE | 每个 token 只激活部分专家的稀疏架构 |
| Preference learning | 从回答相对偏好学习行为 |
| RAG | 检索外部资料后再生成 |
| RLHF | 从人类反馈训练奖励并优化策略 |
| SFT | 用输入-输出示范进行监督微调 |
| Token | tokenizer 产生的模型基本离散单位 |
| Tool calling | 模型选择外部函数并生成结构化参数 |
| Transformer | 以注意力和前馈层为核心的序列架构 |
