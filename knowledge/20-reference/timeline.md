# 总时间线

| 阶段 | 代表性变化 | 系统意义 |
|---|---|---|
| 规则与符号 | 显式知识与逻辑 | 可解释但难覆盖开放世界 |
| 统计学习 | 从语料估计概率 | 数据驱动替代大量手写规则 |
| 深度表示 | 端到端特征学习 | 迁移与规模化成为可能 |
| Transformer | 并行注意力 | 大规模预训练基础 |
| 基础模型 | 预训练 + 提示/微调 | 一个模型覆盖多任务 |
| 指令与偏好 | SFT/RLHF | 从续写器到助手 |
| 增强系统 | RAG、工具、Agent | 从回答到访问动态世界并行动 |
| 推理与多模态 | 测试时计算、统一模态 | 从快速生成到更长思考和实时交互 |
